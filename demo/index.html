Complete ML Artifact Lifecycle

Every step in the lifecycle — from model training to governed production deployment — connected by KitOps.

01
🧠

Train Model

Train XGBoost on fraud detection dataset using Python & scikit-learn

python train_fraud_model.py
accuracy: 0.9835 f1: 0.7143
02
📦

Package with KitOps

Bundle model, dataset, and code into a versioned OCI ModelKit artifact

kit build . -t ghcr.io/myorg/fraud:v1.0.0 kit push ghcr.io/myorg/fraud:v1.0.0
OCI artifact sha256:abc...
03
📋

Register in Kubeflow

Register the ModelKit URI and metadata in Kubeflow Model Registry for lifecycle tracking

registry.register_model(   uri="oci://...fraud:v1.0.0" )
state: LIVE versioned
04
⚙️

Automate with Argo

Run the full pipeline automatically on every training commit via Argo Workflows DAG

argo submit ml-pipeline.yaml   --watch -n argo
automated reproducible
05
🛡️

Govern with Kyverno

Enforce registry allowlists, required labels, and digest pinning via admission policies

kubectl apply -f policies/
enforced compliant
Stack

Four Tools, One Lifecycle

📦
Core

KitOps

OCI-Native ML Packaging

Package ML models, datasets, and code into reproducible OCI artifacts using familiar container tooling. Version, tag, and distribute like Docker images.

  • ✓ OCI standard compliance
  • ✓ Selective layer unpacking
  • ✓ Any OCI registry compatible
  • ✓ Kitfile manifest format
Read Integration Guide →
📋
Registry

Kubeflow Model Registry

Versioned ML Lifecycle Tracking

Track registered models, versions, metadata, and lifecycle states. OCI URI support makes KitOps ModelKits first-class registry artifacts.

  • ✓ RegisteredModel + ModelVersion
  • ✓ OCI URI as ModelArtifact
  • ✓ Python SDK + REST API
  • ✓ LIVE / ARCHIVED / DEPRECATED states
Read Integration Guide →
⚙️
Automation

Argo Workflows

Kubernetes-Native Pipeline Orchestration

Define ML pipelines as YAML DAGs where each step runs in its own container. Insert KitOps packaging as an automatic post-training step.

  • ✓ DAG-based pipeline definition
  • ✓ KitOps executor container
  • ✓ Workflow.uid as artifact tag
  • ✓ Parameterized templates
Read Integration Guide →
🛡️
Governance

Kyverno

Kubernetes-Native Policy Engine

Enforce ML artifact governance with plain YAML policies. No Rego required. Block unauthorized registries, require labels, and prevent mutable image references.

  • ✓ Registry allowlist enforcement
  • ✓ Required label validation
  • ✓ Digest-pin enforcement
  • ✓ Auto-inject KitOps annotations
Read Integration Guide →
